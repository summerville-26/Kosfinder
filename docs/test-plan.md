# Rencana Pengujian (Test Plan) — KosFinder

Dokumen ini memuat rencana pengujian fungsional dan non-fungsional aplikasi **KosFinder** berdasarkan Acceptance Criteria (AC) pada [docs/PRD.md](file:///d:/Tugas%20kuliah/flutterprojek/kosfinder/docs/PRD.md), mencakup skenario positif (alur normal) serta skenario negatif (hasil kosong, tanpa internet, input tidak valid, dan pencegahan modifikasi oleh pemilik lain melalui Row Level Security/RLS).

---
